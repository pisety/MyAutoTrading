# MyAutoTrading (주식/코인 자동매매 시스템)

이 저장소는 개인용 주식 및 가상화폐 자동매매 시스템을 위한 **Monorepo (통합 저장소)** 입니다.
클라이언트인 안드로이드 앱과 백엔드인 파이썬 트레이딩 엔진이 함께 포함되어 있습니다.

## 📂 프로젝트 구조

- **[`AutoTradingApp/`](./AutoTradingApp/)**: 모니터링 및 수동/자동매매 제어를 위한 안드로이드 클라이언트 앱 (Kotlin, Jetpack Compose)
- **[`py-my-auto-trading/`](./py-my-auto-trading/)**: 실시간 시세 수집 및 조건(급등 감시 등)을 평가하여 실제 매수/매도 주문을 실행하는 백엔드 엔진 (Python)

## 🔗 동작 방식

1. **Python 엔진**이 증권사(한국투자증권)와 코인 거래소(업비트) API를 통해 시세를 실시간으로 감시합니다.
2. 사용자가 **Android 앱**을 통해 설정한 '급등 감시 조건(시간, 수익률, 수량 등)'이나 '자동매매 스위치' 상태가 **Firebase Realtime Database**에 실시간으로 업데이트됩니다.
3. 파이썬 엔진은 Firebase에서 변경된 설정을 즉시 감지하고, 해당 조건이 만족되면 자동으로 매수 주문을 넣습니다.

## ⚠️ 중요 보안 안내

본 프로젝트에는 실제 계좌와 연동되는 **API 키**와 **Firebase 인증 파일**이 필요합니다.
보안을 위해 실제 키 파일은 저장소에 업로드되지 않습니다.
각 프로젝트의 템플릿 파일(`keys_template.json`, `google-services_template.json`)을 참고하여 로컬 환경에 직접 키를 세팅해야 합니다. 자세한 설정 방법은 각 하위 폴더의 README를 참고하세요.
